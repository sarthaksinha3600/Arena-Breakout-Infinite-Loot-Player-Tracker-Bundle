## 🧩 Troubleshooting – Fix Common Problems Fast

### 😕 The app won’t start after clicking it.
- **Right-click the app icon** and choose **"Run as administrator"**..
- **Check Windows Defender** – if it blocked it, click "Allow" or "More info" → "Run anyway"..
- **Make sure you extracted everything** if you downloaded a ZIP file (right-click → Extract All) before running..

### 🎯 ESP boxes don’t appear in game.
- **Switch the game to Windowed Borderless** (Settings → Display → Mode)..
- **Ensure the tracker is running BEFORE you launch the game**..
- **Press the `Insert` key** on your keyboard to toggle the overlay on/off..

### 🔊 No sound alerts.
- Check your Windows volume mixer – make sure the tracker isn’t muted (click the speaker icon on the taskbar while the game runs)..
- Raise the "Raid Alerts" volume slider inside the app from 50% to 100%.

### 🔄 The app says "Update available."
- Click "Update Now" and wait. It will download the latest version automatically..
- If it fails, close the app, reopen it, and try again..

### ❓ I accidentally turned something on and now it’s distracting.
- Press `Delete` on your keyboard to reset all toggles to default (ERTSP off, Radar off, Alerts on)..
- Or just click "Reset All" at the bottom of the app window..
